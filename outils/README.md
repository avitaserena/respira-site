# Respirà — outils internes

Dossier des outils réservés à Sabrina (CRM, maquette artisan, futurs outils).
Il est publié sur un sous-domaine protégé : crm.respirà.fr (crm.xn--respir-nta.fr).

- `public/index.html` : le CRM
- `public/maquette-artisan/` : la maquette du tableau de bord artisan
- `public/_headers`, `robots.txt` : l'outil n'est pas indexé par les moteurs de recherche
- `wrangler.jsonc` : configuration Cloudflare (Worker avec fichiers statiques)

Pour ajouter un outil : créer un dossier dans `public/` avec un `index.html`.
Les documents internes (business plan, grille tarifaire…) ne se publient pas ici.
